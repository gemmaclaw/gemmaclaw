The line `high = len(arr)` sets the upper boundary of the search range to the total length of the array. However, array indices in Python (and most programming languages) are zero-indexed. If an array has $N$ elements, the valid indices range from $0$ up to $N-1$.

Methodology

Each task is scored either deterministically (exact-match or rule-based) or by an LLM judge that grades against a per-task rubric (max score reflects rubric weight, typically 5 for easy, 10 for medium, 15 for hard). A task counts as a pass when it scores at least 60%. Speed is measured in tokens per second of completion output, recorded per task and aggregated as median over the run. Total time covers the full 15-task suite end-to-end on a single GPU. Hardware is auto-detected, including WSL2 GPU detection via /usr/lib/wsl/lib/nvidia-smi. All runs are deterministic at temperature 0 unless a task explicitly requires creative generation.
