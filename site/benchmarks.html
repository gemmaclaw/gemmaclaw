Methodology

Each task is scored by an LLM judge against the task rubric after the run is inspected for harness errors. A task counts as a pass when it scores at least 60%. Speed is measured in tokens per second when available, recorded per task and aggregated as median over the run. Total time covers the full agent suite end-to-end on a single GPU. Hardware is auto-detected, including WSL2 GPU detection via /usr/lib/wsl/lib/nvidia-smi. Runs must use the documented backend template and preserve per-task artifacts so failed or suspicious tests can be rerun individually.
